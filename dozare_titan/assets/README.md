# Resurse aplicatie

## logo.png

Logo-ul afisat in antetul documentelor generate ("Fisa limita -cda" si
"RetDozare", atat in .xlsx cat si in .pdf). Acum este un **PLACEHOLDER**
generat automat.

Ca sa pui logo-ul oficial:

1. Redenumeste imaginea oficiala `logo.png`.
2. Inlocuieste fisierul de aici (`dozare_titan/assets/logo.png`) cu ea —
   **acelasi nume, aceeasi cale**. Nu trebuie schimbat nimic in cod.
3. Recomandat: PNG, fundal transparent, format lat (ex. 700x200 px sau
   orice raport similar ~3.5:1) — codul redimensioneaza automat pastrand
   raportul de aspect.

Daca fisierul `logo.png` lipseste din acest folder (ex. l-ai sters), 
documentele revin automat la varianta text "ZIROM TITANIUM", ca inainte.
